# Tn5 Count Matrices

## Overview

This document describes the Tn5 count matrices generated by the CHROMA2 ATACseq pipeline. Count matrices capture Tn5 insertion events at different genomic scales:

- **6 matrix types** covering different genomic features
- **Per-sample counts** for fine-grained analysis
- **Aggregated matrices** combining counts across all samples
- **Genrich-only** BAM files used for consistency
- **Fractional counting** enabled (NH-weighted for multi-mapping reads)

## Matrix Types

### 1. Gene Counts

**File:** `gene/gene_count_matrix.tsv`

Tn5 insertions around transcription start sites (TSS) of protein-coding genes.

- **Binning:** TSS ± 250 bp
- **Features excluded:** rRNA, tRNA, mitochondrial tRNA
- **Use case:** Gene expression accessibility, promoter dynamics
- **Dimensions:** Features × Samples

**Format:**

```
gene_id    gene_name    gene_type    strand    tss_coord    sample1    sample2    ...
```

---

### 2. tRNA Counts

**File:** `trna/trna_count_matrix.tsv`

Tn5 insertions within tRNA gene bodies.

- **Binning:** Midpoint ± 100 bp
- **Size filtering:** Max 1000 bp
- **Use case:** tRNA accessibility, nuclear organization
- **Dimensions:** tRNA features × Samples

---

### 3. Pol III Gene Counts (3 matrices)

**Files:**

- `pol3_pol3_t1/pol3_pol3_t1_count_matrix.tsv` (Type 1 genes)
- `pol3_pol3_t2/pol3_pol3_t2_count_matrix.tsv` (Type 2 genes)
- `pol3_pol3_t3/pol3_pol3_t3_count_matrix.tsv` (Type 3 genes)

Tn5 insertions within RNA polymerase III transcribed genes.

- **Binning:** Full feature span (no flanking region)
- **Size filtering:** Max 1000 bp
- **Use case:** Pol III gene accessibility, 5S/7SL RNA loci
- **Dimensions:** Pol III genes (per type) × Samples

---

### 4. Repeat Element Counts (6 matrices)

**Files:**

- `repeat_sine_alu/` - SINE/Alu repeats
- `repeat_sine_mir/` - SINE/MIR repeats
- `repeat_line_l1/` - LINE/L1 retrotransposons
- `repeat_line_l2/` - LINE/L2 retrotransposons
- `repeat_ltr/` - LTR retrotransposons
- `repeat_other_repeat_elements/` - Other repeat elements

Tn5 insertions within repeat element sequences.

- **Binning:** Full feature span (no flanking region)
- **Size filtering:** Max 1000 bp
- **Use case:** Heterochromatin accessibility, transposon regulation
- **Dimensions:** Repeat elements (per type) × Samples

---

### 5. Viral Genome Counts

**Files:** `viral_{virus}/viral_{virus}_count_matrix.tsv` (per virus)

Tn5 insertions in fixed-size non-overlapping bins across viral genome.

- **Binning:** Fixed 200 bp bins
- **Coverage:** Entire viral genome
- **Use case:** Viral genome accessibility, infection dynamics
- **Dimensions:** 200bp bins × Samples

**Example for Ebola:**

- Genome size: ~19 kb
- Number of bins: ~95

---

### 6. rRNA Counts

**File:** `rrna/rrna_count_matrix.tsv`

Tn5 insertions around TSS of ribosomal RNA genes.

- **Binning:** TSS ± 250 bp
- **Use case:** Ribosomal gene transcription, nucleolar dynamics
- **Dimensions:** rRNA loci × Samples

## Matrix Format

All count matrices follow this standard format:

```
feature_id    feature_name    [feature_type]    [strand]    sample1    sample2    sample3    ...
```

### Columns:

1. **feature_id**: Unique identifier (gene_id, repeat_id, bin_id, etc.)
2. **feature_name**: Descriptive name (gene_name, repeat type, etc.)
3. **Optional metadata**: Type, strand, reference position, etc.
4. **Sample columns**: One per sample, containing Tn5 insertion counts

### Count Values:

- **Integer counts** when multi-mapping reads map to single feature
- **Fractional counts** when multi-mapping reads distribute (1/NH per alignment)
- **Zero** when no Tn5 insertions detected

---

## Counting Method

### Fractional Counting (Enabled by Default)

When a multi-mapping Tn5 read aligns to multiple locations:

```
Single-mapped read (NH=1):   +1.0 count
2-way mapped read (NH=2):    +0.5 count per location
3-way mapped read (NH=3):    +0.333 count per location
...
```

**Rationale:** Prevents bias from over-counting multiply-aligned insertions, especially important for:

- Highly repetitive regions
- Paralogous genes
- Multi-copy transposons

### BAM Filtering

All counting uses Genrich BAM files with:

- MAPQ ≥ 0 (default)
- Secondary alignments excluded (optional)
- Supplementary alignments excluded (default)

## Per-Sample vs Aggregated Counts

### Per-Sample Counts

Location: `{matrix_type}/{sample}.{type}_counts.tsv`

Individual sample counts useful for:

- Quality control (count distribution per sample)
- Sample-level analysis
- Detecting sample-specific accessibility patterns

### Aggregated Matrices

Location: `{matrix_type}/{type}_count_matrix.tsv` and `final_matrices/`

Combined counts across all samples useful for:

- Global accessibility patterns
- Comparative analysis across samples
- Batch effect detection
- Downstream statistical analysis

**Aggregation method:** Simple column-wise concatenation (no normalization)

## Configuration Parameters

All parameters configurable in `config/config.yaml` under `count_matrices`:

```yaml
count_matrices:
  gene_counts:
    enabled: true
    flank_size: 250 # ±250 bp around TSS
    exclude_features: [rRNA, tRNA, Mt_tRNA]

  trna_counts:
    enabled: true
    flank_size: 100 # ±100 bp around midpoint
    max_size: 1000 # Exclude features > 1000 bp

  pol3_counts:
    enabled: true
    flank_size: -1 # Full feature span (no flanking)
    max_size: 1000

  repeat_element_counts:
    enabled: true
    flank_size: -1 # Full feature span
    max_size: 1000

  viral_genome_counts:
    enabled: true
    bin_size: 200 # Fixed 200 bp bins

  rrna_counts:
    enabled: true
    flank_size: 250 # ±250 bp around TSS
```

## Using the Matrices

### 1. Quick Summary

```bash
head -20 results/count_matrices/final_matrices/gene_count_matrix.tsv
```

### 2. Count Statistics

```bash
# Sample counts per feature
wc -l results/count_matrices/gene/gene_count_matrix.tsv

# Total insertions per sample (sum of a column)
awk '{s=0; for(i=6;i<=NF;i++) s+=$i; print s}' \
  results/count_matrices/gene/gene_count_matrix.tsv
```

### 3. Load into R

```r
library(data.table)
gene_counts <- fread("results/count_matrices/final_matrices/gene_count_matrix.tsv")
rownames(gene_counts) <- gene_counts$gene_id
counts_matrix <- as.matrix(gene_counts[, -(1:5)])
```

### 4. Normalization

```r
# Library size (column sum normalization)
normalized <- sweep(counts_matrix, 2, colSums(counts_matrix), "/")

# Log2 transform
log2_counts <- log2(normalized + 1)
```

### 5. Comparative Analysis

```r
# Compare gene accessibility between samples
cor(counts_matrix[, c("sample1", "sample2")])

# Identify differentially accessible features
# (Use DESeq2, edgeR, or similar)
```

## Quality Control Checks

### 1. Total Insertion Counts

```bash
for f in results/count_matrices/*/[!f]*_count_matrix.tsv; do
  total=$(awk '{s=0; for(i=NF-1;i<=NF;i++) s+=$i; print s}' $f | tail -1)
  echo "$(basename $f): $total insertions"
done
```

### 2. Feature Coverage

```bash
# How many features with non-zero counts?
awk 'NR>1 {for(i=6;i<=NF;i++) if($i>0) {found=1; break}} found {count++} END {print count}' \
  results/count_matrices/gene/gene_count_matrix.tsv
```

### 3. Sample Correlation

Check for batch effects or sample clustering:

```r
library(corrplot)
corrplot(cor(gene_counts[, -(1:5)]))
```

## Troubleshooting

### Issue: Missing matrices

**Check:** `results/count_matrices/final_matrices/COUNT_MATRICES_INDEX.txt`

- Verify which matrices were enabled in config
- Check corresponding bin folder for per-sample counts

### Issue: Zero counts across all samples

**Likely causes:**

- Feature not found in BAM file (coordinate mismatch)
- GTF/bin file issue (check REF_DIR bins)
- Insufficient Tn5 coverage

### Issue: Very low/high counts compared to other matrices

**Normal scenarios:**

- Viral genomes have fewer insertions than host genes
- rRNA regions may have low accessibility
- Repeats may have high counts if accessible

**Check:** Sample alignment stats and Tn5 enrichment patterns
